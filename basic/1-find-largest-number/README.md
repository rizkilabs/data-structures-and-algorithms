# Find the Largest Number

A simple JavaScript program that finds the largest number in an array
without using `Math.max()`.

## Concepts

- Array
- Looping
- Comparison

## Requirements

- Do not use `Math.max()`
- Use a loop
- Handle an empty array
- Time complexity: O(n)

## Usage

```bash
node findLargest.js
```

## Example

```
Input:  [12, 45, 7, 89, 23]
Output: 89
```

## Edge Cases

- Empty array returns `null`
- Works with negative numbers
- Works with a single-element array

## Complexity

- Time: O(n), the array is traversed once
- Space: O(1), only one extra variable is used
